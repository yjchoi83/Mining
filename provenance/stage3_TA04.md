# TA04 (seed S8, TC05 병합) — Stage-3 proposal

## 1. Working title & contribution
**How few labels does artisanal gold mining need? Label efficiency, asymmetric cross-region transfer, and negative label pooling of AlphaEarth Foundations embeddings for ASGM enforcement.**
우리는 ASGM 탐지에서 AEF embedding이 Sentinel-2 annual composite baseline이 1,000 label로 얻는 정확도를 **약 40 label**(Amazon, ≥25배)·**25 label 미만**(Ghana, >40배)로 달성하지만, 이 이득이 지역 이전에서 **방향 비대칭적으로** 붕괴하고(Amazon→Ghana −0.167 vs Ghana→Amazon −0.298≈chance) source-region label을 pooling하면 로컬 label만 쓰는 것보다 **나빠진다**는 것을 다지역·ASGM 전용 reference로 검정한다 — 이는 label 예산이 수십 점 수준인 galamsey·Amazon 집행 기관이 "어느 지역에서 몇 개를 판독할지"를 결정하기 때문에 중요하다.

## 2. Research questions & falsifiable hypotheses
- **RQ1 (label efficiency)** ASGM 전용 reference와 dimensionality-matched baseline에서도 label-efficiency 이득이 유지되는가? **H1**: label-parity ratio(= S2가 full-label AUC에 도달하는 label 수 ÷ AEF가 같은 AUC에 도달하는 label 수)가 6개 region 중 ≥4개에서 **≥10배**, bootstrap 95% CI 하한 ≥5배. **반증**: ratio<3배, 또는 ASGM-only stratum에서 소멸(→ 이득은 LSM 혼재 artefact).
- **RQ2 (asymmetry)** transfer 손실은 방향 비대칭이며 target 난이도가 아니라 source의 mining-style/배경 다양성으로 예측되는가? **H2**: 6 region·30 ordered pair에서 AEF의 asymmetry index |drop(A→B) − drop(B→A)| 중위수가 S2보다 유의하게 크고(paired Wilcoxon), source-side embedding coverage/entropy가 drop을 예측한다(부호검정 ≥22/30). **반증**: 대칭이거나 S2와 동일 → TC01의 generic covariate-shift 설명으로 흡수.
- **RQ3 (negative pooling)** foreign label pooling은 로컬 label 예산 k에서 해로운가? **H3**: k≥25에서 pooled(source pool + k local) < local-only k, per-fold paired로 ≥4 pair에서 성립하고 crossover k*<50이며, per-region z-score·importance weighting·source-free adaptation 어느 것도 pooled를 local-only 위로 올리지 못한다. **반증**: pooled ≥ local-only → 표준 pretraining 서사로 회귀.

## 3. Real-world problem, stakeholder, use
문제: ASGM(galamsey, garimpo)은 삼림 파괴와 수은 오염의 주요 원인이지만 집행 기관의 판독 예산은 연 수십~수백 점이고, 관행적으로 "다른 나라 label로 학습한 모델을 가져다 쓴다". 그 관행의 이득(label 절감)과 해악(비대칭 전이·negative pooling)이 동일 프로토콜에서 측정된 적이 없다. Stakeholder: **Ghana Minerals Commission**과 galamsey 단속 태스크포스, **Peru(OEFA/SERNANP)·Brazil(IBAMA)** 환경집행, **Minamata Convention** 수은 배출 국가보고. 사용: (i) "로컬 판독 50점이 외국 label 2,000점보다 낫다"는 검정된 label-budget 지침, (ii) 순찰 우선순위용 확률 지도 + design-based 면적 추정치(±CI)를 수은 부하 proxy·보고 지표로 투입, (iii) label-free 유사도 검색은 쓰지 말라는 문서화된 negative result.

## 4. Data
- **AEF** `GOOGLE/SATELLITE_EMBEDDING/V1/ANNUAL` **2019 primary**(Maus epoch 정합), **2021·2023 replication**(calendar-year semantics [V]).
- **Regions(6)**: Amazon — Tapajos, Madre de Dios, Roraima; West Africa — Ghana SW(Tarkwa/Obuasi 산업광산은 별도 LSM stratum으로 분리), Ghana Ashanti/Offin, Côte d'Ivoire.
- **Reference**: (a) `global_mining_polygons` (Maus et al., 10.1038/s41597-022-01547-4 [V]) — GEE에서 판독 확인, 면적·형상·compactness로 **ASGM/LSM 층화**해 sampling frame으로만 사용. (b) **필수 ASGM-only reference**: Amazon은 **Amazon Mining Watch** annual ASGM mask [U, 세션 내 미검증 → 확보 실패 시 CONDITIONAL 조건 위반], Ghana는 **VHR 판독 galamsey sample**(n≥500, Planet/Google VHR, 2 독립 판독자, 판독 규칙 = 활성 pit + turbid pond + bare spoil 인접, Cohen's κ 보고, 불일치는 3자 조정). (c) Negative frame: Maus polygon 주변 1.5–12 km annulus × `UMD/hansen/global_forest_change_2025_v1_13` lossyear 2015–19(농업성 forest loss = hard negative) / loss 없음+treecover>50(stable).
- **독립성 논거**: AMW는 Sentinel-2 CNN 계보이므로 AEF와 계보가 분리되나 **S2 baseline과는 계보를 공유** → 우리 주장(AEF>S2)에 불리한 방향의 보수적 편향이다. VHR sample은 센서·판독자 모두 독립. Maus는 frame 전용이고 accuracy 산정에는 (b)만 사용해 순환을 차단.
- **Sampling design**: region당 학습 pool 3,000점(mining/hard-neg/stable 균형, pos_frac 0.333) + **별개의 design-based accuracy sample**(stratum: predicted-mining / annulus / stable, 층별 배분은 Olofsson et al. 2014 방식 최적배분). group unit = 0.1°(~11 km) block.

## 5. Method
Pipeline: 표준화 → linear probe(LogReg, class-balanced) 주 분석기, capacity confound 통제용 GBT 병행. **Mandatory baselines**: (i) cloud-masked **S2 annual median 8-band**(Stage-2와 동일, 하한), (ii) **dimensionality-matched S2-60**(monthly percentile + harmonic 계수 + Sentinel-1 VV/VH backscatter ≈60 feature) — R2의 "64 vs 8 dim" 반론 직격, (iii) **다른 GFM**: TESSERA 공개 mirror 우선, 불가 시 Prithvi-EO-2.0 [V, arXiv:2412.02732] 및 DOFA/Copernicus-FM [V, arXiv:2503.06312] tile 추론(≥1개 필수, 입력 modality 표 명시), (iv) **운영 rule-based baseline**(Hansen forest loss + JRC GSW turbid-water 규칙) — 기관이 실제로 쓰는 것과의 대조. GFM few-label 평가 관행은 arXiv:2406.18295 [V]와 정합시키되 target(ASGM)·비대칭 축은 신규.
**Ablations**: AEF→PCA-8(대칭 축소), per-region z-score, TC01식 static-decodable dim removal(분업 재사용), importance weighting, source-free adaptation, mining-type stratum(ASGM-only vs mixed) 재현, pit-size별 분해.
**Label-efficiency curve protocol**: region마다 **고정 held-out test block set**(0.1° block으로 공간 분리, 모든 label 예산·모든 feature set·모든 seed에서 동일)을 먼저 잠그고, 학습 label만 k ∈ {10,25,50,100,250,500,1000,full}에서 block-stratified로 20회 재추출 → 평균 AUC ± bootstrap CI, power-law fit으로 label-parity ratio와 그 CI를 산출.
**Evaluation**: GroupKFold-5 on ≥10 km block(random pixel split 금지), paired per-fold Wilcoxon signed-rank + Benjamini-Hochberg, Δ에 bootstrap 95% CI, asymmetry index에 부호검정, retrieval P@100은 base rate 대비 permutation null. **지도 산출물(region별 ASGM 확률/이진 지도)마다 stratified design-based 면적 추정 + 95% CI**(Olofsson et al. 2014 / Stehman & Foody 2019 방식)를 필수 보고하고, user's/producer's accuracy를 층별로 제시.

## 7. Stage-2 pilot evidence, effect size, power
n=2,700/region(mining 900 / hard-neg 900 / stable 900, pos_frac 0.333), 5-fold GroupKFold on 0.1° block(AMZ 82 / GHA 158 block), 5 seed. Full-data ROC-AUC: **AMZ AEF 0.855(sd .027) vs S2 0.638(sd .052), Δ=0.217**; **GHA AEF 0.977(sd .008) vs S2 0.867(sd .037), Δ=0.110**. Label-efficiency: AEF는 AMZ에서 약 40 label에 S2의 1,000-label AUC(0.635)를 통과, GHA에서는 25 label(0.892)이 이미 S2의 1,000 label(0.865)을 상회. 효과 크기: fold sd 0.027–0.052 대비 Δ=0.217 → Cohen's d ≈ 4–5; pos_frac 0.333·n=2,700에서 AUC의 근사 SE ≈ 0.011이므로 Δ는 SE의 약 20배. Transfer: AMZ→GHA 0.810(−0.167) vs GHA→AMZ **0.557**(−0.298, chance 근접), 반면 S2는 −0.165/−0.052 → asymmetry index AEF 0.131 vs S2 0.113(단일 pair, 검정 미가능 → RQ2의 30-pair 설계 근거). Negative pooling: pooled 0.875 vs local-only 0.895 (k=25), 0.892 vs 0.937 (k=100) → Δ=0.020/0.045, 5 seed로는 marginal이므로 **k당 20 draws**로 설계(Δ=0.03, seed sd 0.03 가정 시 80% power). Power(RQ2): pair-level asymmetry sd 0.05 가정 하 Δ=0.06을 80% power(α=.05, paired)로 검출하려면 ≥8 ordered pair → 30 pair 설계로 충족. 정직한 반대 증거: **retrieval 실패**(AMZ P@100 0.376 vs base 0.333, GHA 0.001) — label-free 검색 모드는 성립하지 않으며, TC01의 per-region z-score 완화도 AEF 전이를 회복시키지 못했다(0.810→0.794; S2는 0.702→0.751로 개선).

## 8. Threats to validity & mitigations
(a) **Label composition — 구속적 위협**: Maus polygon은 ASGM/LSM을 구분하지 않고 Ghana box는 Tarkwa·Obuasi 산업광산을 포함하므로, 25배 label 이득과 "Ghana가 더 쉽다(0.977 vs 0.855)"는 지역 난이도 비대칭이 **동시에 artefact일 수 있다** → ASGM-only reference(AMW + VHR galamsey sample)를 **필수 산출물**로 계획·비용화(§9), Maus는 frame 전용으로 격하, F4에서 두 reference의 결과를 나란히 보고하고 불일치 시 ASGM-only 값을 주 결과로 채택.
(b) **feature dimension 비대칭**(64 vs 8) → S2-60 및 AEF-PCA-8의 대칭 arm; 또한 AEF@100 label(0.780)이 S2 full 2,160 label(0.638)을 이미 넘으므로 sample-per-parameter로 설명되지 않음을 명시.
(c) **region 난이도 혼입** → ASGM-only stratum에서 난이도를 재측정하고 in-region AUC가 근접한 pair로 matched-difficulty 부분집합을 구성해 RQ2를 재검정.
(d) **hard negative 내 미매핑 ASGM**(보고 AUC는 하한) → negative 표본의 VHR audit(n≥200)로 omission rate를 추정해 보정 상한을 제시.
(e) **10 m / annual 한계**: ASGM pit은 종종 <10 m·계절적 → minimum mappable unit을 VHR로 측정하고 pit-size별 detection curve로 보고, turbid-water 계절성은 다년 replication으로 흡수.
(f) spatial autocorrelation → ≥10 km block + 지리적으로 분리된 region 간 전이만 사용. (g) **input-availability artefact**: AEF/S2 모두 구름·S1 결측 지역에서 성능이 다를 수 있어 관측 가용성 공변량을 회귀에 포함. (h) Maus 단일 epoch·연도 속성 부재 → AMW annual mask로 연도 정합. (i) **GEE restricted mode**로 4°×4° stratifiedSample이 타임아웃 → annulus 축소 + asset 사전계산/export 경로 확정(Stage-2에서 검증된 우회).
(j) **윤리·provenance**: 개인·소규모 광부 식별이 아니라 grid(1 km) 집계 지도와 면적 추정치만 공개하고, 좌표 수준 산출물은 기관 요청 시 제한 배포한다는 정책을 논문에 명시.
**TC01과의 분업**: TC01은 land-cover라는 대칭적 과제에서 AEF *representation 내부*의 static/climate-decodable subspace가 cross-region 손실의 원인 성분인지를 dimension-level로 귀속하고 완화 recipe를 만든다. TA04는 그 문제의 **domain-specific instance**로서, 단일 sparse-label 집행 target에서 (i) label-budget 축, (ii) 손실의 **방향 비대칭**, (iii) **pooling의 해악**을 측정한다 — transfer-loss 메커니즘은 TC01의 framing을 그대로 인용해 재도출하지 않는다. 연결 예측: TC01의 static contrast가 크면 asymmetry index도 커야 하며, 성립 시 상호 검증, 불성립 시 "ASGM 비대칭은 static 의존이 아니라 mining-style 다양성" 이라는 별개 발견이 된다.
